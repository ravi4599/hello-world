Post EMR Installation

Config Changes:

1. copy shiro.ini from s3 config path to /etc/zeppelin/conf path (for zeppelin user credentials)

2. Zeppelin Config Changes

	2.1 Stop zeppelin service(master node command prompt, "stop zeppelin")
	2.2 Check below configurations are present in /etc/zeppelin/conf/zeppelin-env.sh 

		export ZEPPELIN_NOTEBOOK_USER=dev-setsail-zepl
		export ZEPPELIN_NOTEBOOK_S3_BUCKET=dev-setsail-zepl
		export ZEPPELIN_NOTEBOOK_STORAGE=org.apache.zeppelin.notebook.repo.S3NotebookRepo
		export PYSPARK_PYTHON=/home/hadoop/anaconda/bin/python
		export PYSPARK_DRIVER_PYTHON=/home/hadoop/anaconda/bin/python
	2.3 Start zeppelin service (master node command prompt, "start zeppelin")

3. Zeppelin UI Config changes
	
	Python Config Changes: Steps
	3.1 Login zeppelin with admin credentials
	3.2 Select user -> Interpreter
	3.3 Search "python" -> Click on "Edit"
	3.4 CHANGE: In Options section, the interpreter will be instantiated "PER USER" in "ISOLATED" process.
	3.5 In Properties section, check "zeppelin.python" value is "/home/hadoop/anaconda/bin/python"
	3.6 Save and Restart the interpreter
	
4. Zeppelin UI Config changes
	
	Pyspark Config Changes: Steps
	4.1 Login zeppelin with admin credentials
	4.2 Select user -> Interpreter
	4.3 Search "spark" -> Click on "Edit"
	4.4 CHANGE: In Options section, the interpreter will be instantiated "PER USER" in "ISOLATED" process.
	4.5 In Properties section, change "zeppelin.pyspark.python" value as "/home/hadoop/anaconda/bin/python"
	4.6 Save and Restart the interpreter
